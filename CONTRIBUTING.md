# Contributing to Tensor Lattice Neural Layer (TLNL)

First off, thank you for taking the time to contribute! 🎉 TLNL is an open-source project, and we appreciate help from the global developer community to make it better.

Please take a moment to review the guidelines outlined below to make your contribution process smooth and effective.

---

## 🛠️ How Can You Contribute?

* **Reporting Bugs:** If you encounter any bugs, errors, or unexpected behavior while using TLNL, please open an issue on GitHub.
* **Suggesting Enhancements:** Have an idea for a new feature, a performance optimization, or better VRAM management? Open an issue to discuss it with us.
* **Submitting Code:** Fix bugs or implement new features by submitting a Pull Request (PR).

---

## 📋 Pull Request Process

1. **Fork the Repository:** Click the "Fork" button at the top right of the repository page.
